# AI-Powered Food Waste Prediction and Redistribution System

This project is designed for the assignment titled:

AI-Powered Food Waste Prediction and Redistribution Intelligence

## Overview
This system predicts food demand and identifies surplus food before it becomes waste. It helps restaurants and food suppliers estimate how much food may be left over and recommends redistribution to shelters, community kitchens, or food banks.

## Objectives
- Analyse historical food demand and supply data
- Forecast expected food demand
- Identify surplus food
- Recommend redistribution opportunities
- Reduce food waste and improve planning

## Technology Stack
- Python
- Streamlit
- Pandas
- Scikit-learn
- NumPy

pip install -r requirements.txt
